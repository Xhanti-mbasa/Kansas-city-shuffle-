# Workshop Flow

## Before the event

- Create the VMs in `virt-manager`
- Take clean snapshots
- Confirm the network
- Start Wazuh and the target server

## During the event

- Red Team activity drives alerts
- Blue Team watches the dashboard
- Tier 1 triages first
- Tier 2 investigates
- Tier 3 supports deeper analysis
- Incident Responder coordinates action

## After the event

- Review the timeline
- Review the evidence
- Score the team
- Reset the lab

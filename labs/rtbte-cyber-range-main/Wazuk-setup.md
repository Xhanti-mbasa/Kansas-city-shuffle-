# Wazuh Setup

### Installation Overview

In order to monitor events on the virtual machine, also known as an **agent**, we will be using [Wazuh](https://wazuh.com/), an open source **SIEM (Security Information and Event Management)** platform.

This documentation serves as an **installation guide** and does not cover how to use or configure Wazuh after installation. For more information about Wazuh, visit their website or watch the recommended video below.

* [YouTube: This Cybersecurity Platform is FREE](https://youtu.be/i68atPbB8uQ?si=0bvSbjJ9tlwF0hMB) by John Hammond

## Installing Wazuh

Run the following command to download and execute the Wazuh installation assistant:

```bash
sudo dnf install -y curl
curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh
sudo bash wazuh-install.sh -a
```


## Access the Wazuh Dashboard

From a browser inside the Ubuntu virtual machine, navigate to:

```text
https://10.0.2.15
```

Replace `10.0.2.15` with the IP address assigned to your Wazuh virtual machine.

This should open the Wazuh dashboard. Log in using the `admin` credentials generated during the installation.

> **Note:** Because Wazuh uses HTTPS with its own certificates, your browser may display a certificate warning during the first visit. This is expected with the default installation certificates.

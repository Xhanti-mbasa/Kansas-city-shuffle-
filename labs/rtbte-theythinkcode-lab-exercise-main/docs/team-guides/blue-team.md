# Blue Team Guide

## Purpose

The Blue Team acts like a SOC and monitors the target through Wazuh.

## What each role does

- Tier 1: triage and filter
- Tier 2: investigate and correlate
- Tier 3: deep analysis
- Incident Responder: coordinate containment
- Threat Hunter: search for missed activity
- Security Engineer: maintain visibility and tools
- Reporting Analyst: write the final record

# Workshop Overview

This workshop simulates a real SOC responding to activity against a vulnerable school website server.

## Goal

- Monitor the target
- Detect suspicious activity
- Investigate alerts
- Contain confirmed incidents
- Document the findings clearly

## Core parts

- Target server: hosts the website and runs the Wazuh agent
- Wazuh server: collects events and shows alerts
- Analyst team: 7 people sharing the dashboard and SOC workflow

## Team model

The analysts share the same dashboard but perform different duties:

- Tier 1 triage
- Tier 2 investigation
- Tier 3 deep analysis
- Incident response
- Threat hunting
- Security engineering
- Reporting and threat intelligence

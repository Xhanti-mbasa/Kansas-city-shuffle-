# Wazuh Setup

## Purpose

The Wazuh server collects events from the target machine and shows alerts to the whole SOC team.

## Model

- Install the Wazuh manager and dashboard on one VM
- Install the Wazuh agent on the target website server
- Give all analysts dashboard access

## Workshop behavior

- Tier 1 watches incoming alerts
- Tier 2 investigates suspicious activity
- Tier 3 handles deeper analysis

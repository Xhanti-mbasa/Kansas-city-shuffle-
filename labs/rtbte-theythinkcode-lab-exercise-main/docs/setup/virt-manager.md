# virt-manager Setup

## What to create

- One target VM for the website and Wazuh agent
- One Wazuh server/dashboard VM

## Suggested workflow

1. Create the VMs in `virt-manager`
2. Put them on the same lab network
3. Assign fixed hostnames
4. Take a clean snapshot before the exercise

## Notes

- The analysts do not need one dashboard VM each
- All 7 analysts can use the same dashboard in Chrome
